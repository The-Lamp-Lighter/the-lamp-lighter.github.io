O histórico de versões aqui é editado à mão em data/projects.js — é o jeito seguro de fazer isso num site estático (sem servidor). Quando um projeto já tiver repositório de verdade no Diversion, preencha o campo diversionUrl dele com o link do workspace: aparece um botão "Abrir no Diversion" que leva direto pro repositório real, num clique. Não dá pra embutir a interface do Diversion aqui dentro (apps com login bloqueiam isso por segurança), então o link direto é a forma mais confiável de conectar os dois.
